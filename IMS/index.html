Instructions to use AI enriched template for metadata creation

Note: Instructions to use AI enriched template for metadata creation
  • Enter ISBN, (only one) 13 digits or 10 digits if available, and click on AI Generate button to retrieve information on the resource. (note for i-icon)
  • If ISBN is not available, enter the Title and subtitle as seen on the title page in the field for 'Title' and enter the Author's first name and last name into the right fields. Click on AI Generate button. (note for i-icon)
  • Verify the AI generated fields against the details of the physical item. Any blank fields can be completed manually. Check all boxes for the fields that will remain empty.
  • Use 'Search for book with an image' option to search by image of the item to be catalogued.
  • Keywords can be entered using the search terms from the predictive dropdown menu, which uses LOC FAST subject headings.
  • Use 'Select Images' field to add images to the record and upload images. A destination for image storage to be set if you wish the images to be stored on local network or a specific cloud storage. Refer to the Github files to learn more.
  • Save the record to your local computer or to a specific destination by checking the box for right desired format and click on 'Create' button.
  • Refer to the GitHub link below to download and make changes to the template as required.
